# Release v0.1.0 - Initial Local Prototype

## Summary

This first release establishes a safe, local prototype for the EVA Air award alert bot. It validates the end-to-end flow from watchlist configuration to provider results, SQLite state, duplicate suppression, and Telegram-style alerts without connecting to a live ANA/EVA award-search provider.

## Highlights

- Python package with `eva-award-alert` CLI.
- One-shot and watch-mode runner.
- JSON watchlist configuration.
- Full recommended EVA North America-to-Taipei watchlist.
- One-route dry-run trial watchlist.
- Deterministic `stub` and `stub-empty` providers.
- SQLite persistence for search runs, availability results, and alerts.
- Telegram notifier with dry-run default and real `sendMessage` support.
- Duplicate suppression so unchanged award results do not spam alerts.
- Hand-by-hand, trial, Telegram setup, and ANA award-ticket usage documentation.
- Unit tests covering config loading and alert deduplication.

## Safety Notes

- The live ANA Mileage Club / EVA Air provider is not implemented in this release.
- Stub provider results are fake and must not be used for booking decisions.
- Keep committed configs in `dry_run` mode.
- Do not commit Telegram tokens, chat IDs, ANA credentials, cookies, or session data.
- This project must not automate purchases, bookings, login bypasses, or technical-control circumvention.
